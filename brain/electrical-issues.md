# Electrical Issues — Indian Two-Wheelers

## Battery Problems

### Battery Draining Overnight

Very common issue, especially post-monsoon.

Causes (ranked):
1. Old battery past life (sealed VRLA batteries last 2–3 years in Indian climate)
2. Parasitic drain from aftermarket accessories — GPS tracker, USB chargers, LED lights
3. Faulty rectifier-regulator — overcharging kills battery, undercharging doesn't replenish
4. Stator coil weak output
5. Corroded battery terminals (common in coastal areas, after monsoon)

Check:
- Clean terminals with baking soda solution
- Test with multimeter: 12.6V+ fully charged, 13.8–14.4V while running
- Above 15V while running = faulty regulator (kills battery and bulbs)

Cost:
- Battery (7Ah sealed): ₹800–₹1,500
- Battery (9Ah for BS6): ₹1,200–₹2,500
- Rectifier-regulator: ₹600–₹2,000
- Stator replacement: ₹1,500–₹4,000

### Self-Start Not Working, Kick Works

- Weak battery — most common
- Starter motor brushes worn
- Starter motor relay (solenoid) failed — click sound but no crank
- Starter motor jammed

Cost:
- Relay/solenoid: ₹300–₹700
- Starter motor brushes: ₹200–₹500
- Starter motor replacement: ₹1,500–₹3,500

## Lighting Issues

### Headlight Dim / Flickering

Causes:
- Loose or corroded connector at headlight
- Failing regulator-rectifier
- Ageing bulb filament (halogen)
- Earthing issue — check frame ground connections

Cost:
- Halogen bulb H4: ₹100–₹300
- LED retrofit (aftermarket): ₹500–₹1,500
- Regulator-rectifier: ₹600–₹2,000

### Indicators Not Working

- Blown fuse (check fuse box — usually under seat)
- Faulty flasher relay unit
- Individual bulb failure
- Water ingress in connector (monsoon issue)

Cost:
- Fuse set: ₹20–₹50
- Flasher relay: ₹100–₹300
- Indicator bulb: ₹20–₹60

## Fuel Gauge Inaccurate (BS6 FI Bikes)

- Sending unit (float) in fuel tank stuck or corroded
- Speedometer cluster fault (shows full/empty permanently)
- Wiring corrosion

Cost:
- Fuel level sender unit: ₹400–₹1,200
- Cluster replacement if speedometer issue: ₹2,000–₹6,000

## Check Engine / MIL (Malfunction Indicator Lamp) ON

BS6 bikes have OBD port. Common fault codes:

- P0115/P0116: Engine temperature sensor — replace sensor (₹400–₹1,000)
- P0336: Crankshaft position sensor — replace (₹800–₹2,000)
- P0131: O2 sensor lean — check exhaust for leaks first
- P0300: Misfire — spark plug, injector, compression issue
- P0562: Low voltage — battery/charging system issue

Get fault code scanned before any repair. Most authorized service centers use HERO/BAJAJ/HONDA proprietary scanners.

Cost of diagnosis scan: ₹0 at authorized centers, ₹200–₹500 at independent shops with OBD adapter.
